## 3. Модель місць

Ліс один → 3 частини → 8 рукавичок. **Не дерево, а DAG**: «Під вербою» у двох частинах, «На узліссі» — у жодній. Те саме описано в архівному документі «Карта лісу».

| Рукавичка | Хвойна | Листяна | Біля річки |
|---|:-:|:-:|:-:|
| Під ялиною | ● | | |
| У соснах | ● | | |
| Біля мурашника | ● | | |
| Під дубом | | ● | |
| У ліщині | | ● | |
| Під вербою | | ● | ● |
| Біля бобрової греблі | | | ● |
| На узліссі | | | |

Доречні поради для питання про місце X:
- рукавичка → вона + її частини + ліс; «На узліссі» → вона + ліс ✅ (L27)
- частина → частина + ліс; поради рукавичок не додавати ✅ (16:00)
- ліс → лише ліс ✅ R-27 (M-02, 16:56)
- конфлікт рівнів → рукавичка > частина > ліс ✅; конкретна — першою, загальну можна додати ✅ R-24
- поради одного рівня різняться (дві частини «Під вербою»; два документи одного місця) → D-03 ✅
- новий варіант документа → замінює старий ✅ R-15

## 4. Еталон відповіді (L19–21)

Документ «Членські внески» рукавички «Під дубом». Питання: «Скільки внесок під дубом і до якого числа?»

> 4 жолуді з дорослого звіра на місяць, здати до 10 числа Кабанові в кошик біля входу. Замість 4 жолудів можна віддати 2 лісові горіхи. — з документа «Членські внески» рукавички «Під дубом»

Що з цього випливає:
- Місце назване прямо в тексті питання.
- Це архівний документ (`Членські внески рукавички Під дубом.txt`), тому автора й дати в підписі немає ✅ R-12.
- Відповідь бере все, що стосується питання: кількість, строк, кому, куди, заміну. Розділ документа «Хто не платить» (пташенята й поросята до року) в еталон не ввійшов — про це не питали.
- Числа й терміни — дослівно.
- Підпис документа від звіра (наш формат 🔶): `— з документа «Назва» рукавички «Місце» (надіслано: Ім'я, ДД.ММ.РРРР)`. «Надіслано:» замість «надіслав/надіслала» — рід невідомий.

**M-34** · D-45 дата
> Щодо дат: бот знатиме сьогоднішню дату й день тижня. На питання на кшталт «чи можна сьогодні переходити брід?» він застосує пораду до сьогоднішнього дня – наприклад, нагадає, що гребля відкривається у вівторок і п'ятницю вранці. **M-35** · D-46 розрахунки
> Щодо розрахунків: якщо звір попросить, бот порахує за порадою й покаже, як саме рахував. Наприклад: «3 дорослі × 4 жолуді = 12 жолудів, поросята до року не платять». Так звір зможе перевірити розрахунок, а бот завжди вкаже документ, з якого взяв правило.

Пастки для класифікації за назвами місць:
- «Як не заблукати серед однакових сосен» — хвойний ліс, а не рукавичка «У соснах»;
- «Броди і коли бобри відкривають греблю» — біля річки, а не рукавичка «Біля бобрової греблі»; у тексті ще «Біля верби» ≠ «Під вербою»;
- «Що робити при пожежі» — весь ліс, хоч у тексті «Усі збираються біля бобрової греблі».

Закладені конфлікти (→ eval):
- «Під вербою», коли йти по гриби: у листяному лісі — на 4–5 день після дощу, біля річки — наступного дня → D-03. Імовірно, так само з утепленням і небезпеками (частина документів — скани, звірити після OCR);
- конкретніше важливіше: «Коли падають жолуді й горіхи» (листяний: жолуді з середини вересня до кінця жовтня) проти «Календаря сезонів» (ліс: у жовтні); «Як утеплити рукавичку в листяному лісі» (коли облетить листя, до першого снігу) проти «Календаря сезонів» (у листопаді); грибні путівники частин проти «Осіннього путівника лісу» і «Їстівного й отруйного» (просто «після дощу»);
- «На узліссі»: поради частин не діють — так написано й у «Карті лісу».

Імовірні сценарії перевірки: у «Статуті ОСМД Під дубом» голова — Сова, скарбник — Кабан. Отже, можна чекати нових «Членських внесків рукавички Під дубом» від Кабана й нового «Осіннього путівника лісу» від Сови. Новий варіант із Telegram замінює архівний (R-15), а в підписі з'являються ім'я й дата.

# 0001. Telegram-фреймворк — aiogram 3

Статус: прийнято · 17.10.2026 · Вимоги: C-01, R-06, R-08, D-37

## Контекст

Бот веде багатокрокові діалоги: спитати ім'я, перепитати місце, підтвердити заміну документа. Йому потрібні кнопки, прийом файлів і тести діалогів без справжнього Telegram.

## Рішення

aiogram 3:
- роутери для команд, документів і питань;
- FSM зі станом діалогу в Postgres, тож очікування імені, місця чи підтвердження переживає рестарт;
- middleware для доступу (0017), ліміту запитів і correlation id;
- `Dispatcher.feed_update` для e2e-тестів (0010).

## Наслідки

- Увесь стек асинхронний: asyncpg і асинхронний HTTP-клієнт.
- Сховище FSM у Postgres пишемо самі, бо зі стандартних є лише пам'ять і Redis.

## Альтернативи

- **python-telegram-bot** — рівноцінний за зрілістю. Але `feed_update` і middleware в aiogram прямо лягають на тести й наскрізні перевірки.
- **pyTelegramBotAPI** — синхронне коріння, асинхронність додана збоку.

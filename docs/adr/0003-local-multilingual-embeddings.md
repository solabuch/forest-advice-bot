# 0003. Локальна багатомовна модель embeddings

Статус: прийнято · 17.10.2026 · Вимоги: C-03, C-04, D-30

## Контекст

- Документи бувають будь-якою мовою, а питання — українською (D-30).
- Embeddings у безкоштовному Groq не підтверджені.
- Ще один API означав би третій токен, а запуск має вимагати лише два (C-03, C-04).

## Рішення

- Локальна багатомовна модель на CPU через ONNX, вшита в Docker-образ.
- Кандидати: multilingual-e5 (small або base) і bge-m3.
- Обираємо за трьома мірками:
  - hit@k на перевірочних питаннях з архіву;
  - розмір образу;
  - час CPU на документ.

## Наслідки

- Embeddings не залежать від мережі й лімітів API.
- Образ важчий, тому пріоритет — менша модель і int8.
- Вибір моделі обґрунтований цифрами з eval.

## Альтернативи

- **Groq embeddings** — недоступні або не підтверджені на безкоштовному тарифі.
- **OpenAI, Cohere, Jina API** — ще один ключ і оплата.
- **sentence-transformers + torch** — образ на кілька гігабайтів.

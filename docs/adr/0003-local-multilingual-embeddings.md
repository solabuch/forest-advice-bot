# 0003. Локальна багатомовна модель embeddings

Статус: прийнято · 17.10.2026, модель обрано 18.10.2026 · Вимоги: C-03, C-04, D-30

## Контекст

- Документи бувають будь-якою мовою, а питання — українською (D-30).
- Embeddings у безкоштовному Groq немає: `GET /models` 18.10 повертає лише чат, аудіо й класифікатори.
- Ще один API означав би третій токен, а запуск має вимагати лише два (C-03, C-04).

## Рішення

- Локальна багатомовна модель на CPU через ONNX, вшита в Docker-образ.
- **Модель — `multilingual-e5-small`, int8** (`Xenova/multilingual-e5-small`, `onnx/model_quantized.onnx`):
  - 384 виміри;
  - ревізія закріплена комітом, файли перевіряються за sha256.
- **Рантайм — onnxruntime + tokenizers + numpy**, без torch:
  - префікси `query:` / `passage:`;
  - mean pooling, L2-нормалізація;
  - обрізання до 512 токенів.
- **Фрагменти обробляються по одному, без батчів:**
  - на цьому CPU батчі не швидші: 37 мс на фрагмент проти 42 мс батчем по 16;
  - у int8 з динамічним квантуванням вектор залежав би від сусідів по батчу (косинус до 0,9958).
- **Вибір підтверджує eval (S-08)** — hit@k на питаннях з архіву. Перехід на іншу модель = міграція розмірності + перерахунок векторів; на сотнях документів це хвилини.

## Цифри (18.10, `scripts/bench_embeddings.py`, Intel i3-7020U)

12 українських пар «питання → фрагмент» + 3 міжмовні, пул із 15 фрагментів:

| Варіант | Файл | hit@1 укр | MRR укр | hit@1 між мовами |
|---|---|---|---|---|
| int8 | 118 МБ | 10/12 | 0,917 | 0/3 |
| fp32 | 470 МБ | 10/12 | 0,917 | 0/3 |

- **Квантування якість не зіпсувало:** косинус int8 ↔ fp32 — у середньому 0,996.
- **Промахи — майже нічия** (0,806 проти 0,804): їх закриває гібридний пошук і top-k > 1 (ADR-05).
- **Час:** запит — 8–16 мс, фрагмент на ~100 токенів — 25–40 мс.

## Наслідки

- Embeddings не залежать від мережі й лімітів API.
- **Образ важчий:** стиснутий 111 → 252 МБ, розпакований 311 → 617 МБ.
  - модель — 130 МБ;
  - onnxruntime — 69 МБ;
  - numpy — 70 МБ;
  - tokenizers із транзитивним huggingface-hub — 38 МБ.
- **Старт:** модель вантажиться 1,9 с; перший запуск після збірки — до 10 с, поки диск не в кеші.
- **Міжмовний пошук у e5-small слабкий:** українське питання не знаходить англійський, польський чи німецький фрагмент. Архів увесь українською, тож це стосується лише нових документів іншою мовою (D-30). Рішення — в S-05: такий документ один раз перекладається для індексу, а в джерелі лишається оригінал.

## Альтернативи

- **Groq embeddings** — немає на безкоштовному тарифі.
- **OpenAI, Cohere, Jina API** — ще один ключ і оплата.
- **sentence-transformers + torch** — образ на кілька гігабайтів.
- **`multilingual-e5-base` / `bge-m3`** — кращий міжмовний пошук, але модель у 2–5 разів більша й повільніша на CPU. Повернемось до них, якщо eval покаже, що small не вистачає.
- **`model_qint8_avx512_vnni.onnx` від intfloat** — квантований під AVX512-VNNI без `reduce_range`. На AVX2 й ARM можливе насичення й втрата точності, а розмір той самий.

# 0016. Місце документа: фраза → LLM → перепитати

Статус: прийнято · 17.10.2026 · Вимоги: R-07, R-08, R-16, D-21

## Контекст

- Документ стосується рівно одного місця (R-07), і вгадувати не можна (R-08).
- В архіві назва місця явно стоїть у першому абзаці: «Ця пам'ятка для мешканців біля річки».
- Водночас архів містить пастки:
  - «Як не заблукати серед однакових сосен» стосується хвойного лісу, а не рукавички «У соснах»;
  - «Броди і коли бобри відкривають греблю» стосується частини біля річки, а не рукавички «Біля бобрової греблі»;
  - «Що робити при пожежі» — для всього лісу, хоч у тексті є «боброва гребля».

## Рішення

1. **Явна фраза адресата** в першому абзаці («для мешканців …», «Шановні мешканці рукавички …»).
2. **Інакше — LLM** зі structured output: обирає лише зі списку місць і повертає впевненість.
3. **Невпевнено** → кнопки місць для автора.
4. **Поради для кількох місць** → бот просить розділити документ (R-16).
5. **Невідоме місце** → перепитати (D-21).

Назви місць деінде в тексті — лише підказка, не рішення.

**Як шукаємо фразу (18.10, `ingest/place.py`):**
- перше речення першого абзацу, де згадано місце; якщо в тексті немає — назва документа;
- рукавичка — назва в лапках «…» з нечітким порівнянням (OCR читає «У еоснах» замість «У соснах»);
- частина — за основою в будь-якому відмінку: «хвойного лісу», «у листяному лісі», «біля річки», «прибережжя»;
- весь ліс — «мешканців лісу», «всього лісу» без прикметника частини;
- рукавичка разом зі своєю частиною — це рукавичка; дві рукавички, дві частини, ліс і частина в одній фразі — просимо розділити (R-16);
- LLM — лише якщо фрази немає; прийнято при `confidence ≥ 0.8` і лише id з графа.

**Перевірка:** розмітка `eval/archive_places.yaml` (за назвами файлів від Мишки, три без місця в назві — за текстом). Текстові документи — 59/59 без LLM; скани — у CI з tesseract.

## Наслідки

- Архів класифікується без LLM, і це перевіряється в eval (ціль 78/78).
- Пастки не спрацьовують.

## Альтернативи

- **Шукати назви місць по всьому тексту** — падає саме на пастках архіву: «сосни», «гребля», «верба».

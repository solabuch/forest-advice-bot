# 0007. Long polling замість webhook

Статус: прийнято · 17.10.2026 · Вимоги: C-03

## Контекст

Рев'юери запускають бота локально однією командою (C-03). Публічного HTTPS-адреса в них немає.

## Рішення

- За замовчуванням long polling.
- Webhook можна ввімкнути через змінні оточення.
- На старті бот прибирає вебхук, що міг лишитися від іншого запуску.

## Наслідки

- Працює за NAT і без тунелів.
- Один токен — один процес полінгу. Для розробки й демо — різні боти. Конфлікт двох процесів бот пояснює в лозі.

## Альтернативи

- **Webhook** — потрібен публічний HTTPS або тунель (ngrok тощо). Для локального запуску рев'юером це зайвий крок.

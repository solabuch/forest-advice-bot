# 0012. Здача без сервера: автоматизація на GitHub

Статус: прийнято · 17.10.2026 · Вимоги: C-03, C-05

## Контекст

Здаємо посилання на репо. Рев'юери запускають бота локально.

## Рішення

- Деплою на сервер немає.
- Автоматизація на GitHub:
  - PR → CI;
  - merge у `main` → образ у GHCR;
  - release-please → CHANGELOG, тег, GitHub Release.

## Наслідки

- Немає інфраструктури й серверних секретів, яких рев'юер не перевірить.
- Сили йдуть у якість бота й відтворюваний запуск.

## Альтернативи

- **Деплой на VPS** — інфраструктура й секрети без користі для оцінки.

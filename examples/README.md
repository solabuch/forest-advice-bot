# Документи для перевірки

Надішли боту файл через скріпку → «Файл». Першого разу бот спитає твоє ім'я: звірі бачитимуть у відповідях, хто надіслав пораду (D-34).

Що бот відповідає на кожен із цих документів, перевіряє [`tests/integration/test_examples.py`](../tests/integration/test_examples.py).

## Місце документа

| Файл | Що перевіряє | Що робить бот |
|---|---|---|
| `Членські внески рукавички Під дубом (новий варіант).txt` | Новий варіант документа з архіву: внесок 5 жолудів замість 4, строк до 15 числа (D-37) | «Схоже, … — новий варіант документа «Членські внески рукавички «Під дубом»» (… з «Лісового архіву»)», кнопки «Так, замінити» / «Ні, це окремий документ». Після заміни старий варіант перестає діяти |
| `Як сушити гриби.txt` | Місце не назване (R-08) | Не вгадує: «Для якого місця «Як сушити гриби»?» і кнопки з місцями лісу |
| `Листопад у рукавичці Під кленом.txt` | Рукавички «Під кленом» у лісі немає (D-21) | Називає незнайому рукавичку й пропонує обрати місце кнопкою |
| `Чергування рукавичок Під дубом і У ліщині.txt` | Поради для двох місць в одному документі (R-16) | Просить розділити документ на два й не додає його |

## Формати (D-14)

Усі ці документи бот приймає сам і визначає місце за першим абзацом, без LLM (ADR-16).

| Файл | Формат | Місце |
|---|---|---|
| `Нічна тиша в рукавичці У соснах.pdf` | скан без текстового шару, OCR триває ~5 с | рукавичка «У соснах» |
| `Як перезимувати біля річки.doc` | старий Word | частина лісу біля річки |
| `Розклад толоки в хвойному лісі.docx` | Word з таблицею | хвойний ліс |
| `Свято першого снігу.odt` | OpenDocument | увесь ліс |
| `Ягоди на узліссі.rtf` | RTF | рукавичка «На узліссі» |
| `Як ходити повз мурашник.md` | Markdown | рукавичка «Біля мурашника» |
| `Chanterelles near the anthill.txt` | англійською (D-30): спитай «Коли збирати лисички біля мурашника?» — порада українською, числа збережено | рукавичка «Біля мурашника» |

Після «Готово ✅» під повідомленням є кнопки «Змінити назву» і «Змінити місце» (D-17).

## Без окремих файлів

| Що надіслати | Що робить бот |
|---|---|
| Будь-який файл із [`data/archive/`](../data/archive/) | «Такий самий файл уже є» — той самий файл удруге не додається (A-09) |
| Фото | Просить надіслати пораду файлом (R-05) |
| `.mp3`, `.zip` чи інший формат | Перелічує формати, які читає (D-14) |
| Файл, більший за 20 МБ | Пояснює ліміт Telegram і що зробити (D-16) |
| Кілька файлів одним повідомленням | Читає по черзі, ім'я питає один раз, наприкінці — підсумок (D-53) |

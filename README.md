# Бот порад для звірів лісу

Telegram-бот для мешканців лісу: звірі надсилають документи з порадами, а інші питають і отримують відповідь із посиланням на документ-джерело.

> У розробці. Вимоги й рішення — [docs/requirements.md](docs/requirements.md), розмова із замовницею — [docs/transcript.txt](docs/transcript.txt).
